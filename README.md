# fanhearth
A new indie home for fandom community. We're bringing back the 2000s internet LiveJournal/Tumblr/forums internet heydays.

## GitHub Pages

The site served from `docs/` (info page + password-gated mockups) is a build artifact — it needs to be rebuilt whenever the info page source (`site-src/`) or the mockups (`mockups/`) change. See `mockups/justfile` for the `build` recipe and password setup.
